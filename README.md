# Portfolio Starter (Next.js + Tailwind + Framer Motion)

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`

## Customize quickly

1. Update `app/page.tsx` with your real name, email, GitHub, LinkedIn.
2. Replace project items in `projects` array.
3. Replace skills in `skills` array.
4. Update SEO title/description in `app/layout.tsx`.

## Deploy on Vercel

1. Push this folder to a GitHub repo.
2. Import the repo in Vercel.
3. Keep default settings and deploy.
